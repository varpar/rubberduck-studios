# rubberduck-studios

Rubberduck is an immersive Next.js studio site set around a navigable pond.
It combines a responsive, low-power-aware React Three Fiber scene with
editorial pages for selected work, services, and contact.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production check

```bash
npm run build
npm run start
```
